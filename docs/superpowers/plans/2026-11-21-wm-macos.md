# macOS Window Manager (AeroSpace) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the Mac the shared window-manager keymap from
`docs/superpowers/specs/2026-11-21-window-manager-design.md` with AeroSpace,
managed by chezmoi and verified on this machine.

**Architecture:** Homebrew installs AeroSpace from its own tap through the
repo `Brewfile`. chezmoi places `dot_config/aerospace/aerospace.toml` at
`~/.config/aerospace/aerospace.toml` on macOS only. The config holds the
shared keymap on left Option, pins WezTerm and the browser to their slots, and
opens Raycast "Switch Windows" through a deeplink for the picker.

**Tech Stack:** AeroSpace 0.21.3-Beta, Homebrew 7, chezmoi 2.69.1, Raycast,
prek

## Global Constraints

- `Mod` is left Option (`alt-` in AeroSpace). Do not bind `cmd-` chords.
- Keymap, app slots and picker key follow the spec exactly. Shared changes go
  through a separate spec-only PR merged first; macOS-only corrections stay in
  this PR.
- Public repository: no secrets, private URLs, host names or machine identity
  values.
- `.chezmoiignore`: add `/.config/aerospace/` to the darwin-only block only.
- `scripts/check-chezmoi-managed.sh`: list the new source in `require_source`;
  do not add OS-specific targets to `require_managed` or `require_ignored`.
- User-facing note in Japanese: `docs/window-manager-macos.md`.
- Run `prek run --all-files` before every commit.

AeroSpace documentation facts that differ from the spec text:

- `on-window-detected` uses `if = 'test %{app-bundle-id} = <id>'` since
  0.21.0. The `if.app-id` form in the spec is soft-deprecated
  (guide section "Legacy 'on-window-detected' syntax").
- `on-window-detected` also runs for windows found during AeroSpace startup
  (`MacWindow.swift` checks `isStartup` only for the legacy
  `during-aerospace-startup` matcher).
- With `config-version = 2`, omitted `persistent-workspaces` falls back to an
  empty list, and omitted `mode.main.binding` keys are unbound.

- [ ] **Step 2: Write the config**

Create `dot_config/aerospace/aerospace.toml`:

```toml
# AeroSpace config. Shared keymap: docs/superpowers/specs/2026-11-21-window-manager-design.md
# Mod is left Option (alt-*), the key two to the left of Space under the
# Karabiner "Windows-friendly" profile. Notes: docs/window-manager-macos.md

config-version = 2

start-at-login = true

# Keep the browser and terminal slots filled. `open -b` only activates an app
# that is already running.
after-startup-command = [
    'exec-and-forget open -b com.github.wez.wezterm',
    'exec-and-forget open -b com.microsoft.edgemac',
]

# Slot 1 (game) has no rule: no game is installed on this Mac.
on-window-detected = [
    { if = 'test %{app-bundle-id} = com.microsoft.edgemac', run = 'move-node-to-workspace 2' },
    { if = 'test %{app-bundle-id} = com.github.wez.wezterm', run = 'move-node-to-workspace 3' },
]

[mode.main.binding]
    alt-1 = 'workspace --auto-back-and-forth 1'
    alt-2 = 'workspace --auto-back-and-forth 2'
    alt-3 = 'workspace --auto-back-and-forth 3'
    alt-4 = 'workspace --auto-back-and-forth 4'
    alt-5 = 'workspace --auto-back-and-forth 5'
    alt-6 = 'workspace --auto-back-and-forth 6'
    alt-7 = 'workspace --auto-back-and-forth 7'
    alt-8 = 'workspace --auto-back-and-forth 8'
    alt-9 = 'workspace --auto-back-and-forth 9'

    alt-shift-1 = 'move-node-to-workspace --focus-follows-window 1'
    alt-shift-2 = 'move-node-to-workspace --focus-follows-window 2'
    alt-shift-3 = 'move-node-to-workspace --focus-follows-window 3'
    alt-shift-4 = 'move-node-to-workspace --focus-follows-window 4'
    alt-shift-5 = 'move-node-to-workspace --focus-follows-window 5'
    alt-shift-6 = 'move-node-to-workspace --focus-follows-window 6'
    alt-shift-7 = 'move-node-to-workspace --focus-follows-window 7'
    alt-shift-8 = 'move-node-to-workspace --focus-follows-window 8'
    alt-shift-9 = 'move-node-to-workspace --focus-follows-window 9'

    alt-h = 'focus left'
    alt-j = 'focus down'
    alt-k = 'focus up'
    alt-l = 'focus right'

    alt-shift-h = 'move left'
    alt-shift-j = 'move down'
    alt-shift-k = 'move up'
    alt-shift-l = 'move right'

    alt-f = 'fullscreen'
    alt-shift-space = 'layout floating tiling'

    alt-minus = 'resize smart -50'
    alt-equal = 'resize smart +50'

    # Window picker: Raycast "Switch Windows".
    alt-space = 'exec-and-forget open raycast://extensions/raycast/navigation/switch-windows'
```
